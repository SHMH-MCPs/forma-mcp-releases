# Autodesk Forma MCP

**AI assistants that work with Autodesk Forma (formerly Autodesk Construction Cloud) projects.**

Autodesk Forma MCP is an [MCP](https://modelcontextprotocol.io) server. Claude, ChatGPT, Cursor, VS Code and other AI
assistants use it to read and work with Forma projects through Autodesk Platform Services, acting with the signed-in
user's own Autodesk permissions: documents, issues, RFIs, submittals, forms, sheets, cost, model coordination, takeoff,
AEC Data Model, BuildingConnected and more. High-impact changes need a preview and your explicit confirmation; paid APIs
are off until an administrator switches them on.

**Status:** not yet released, and not yet tested against a real Autodesk account (all tests use a simulated Autodesk).

**Download:** when a release exists, [the latest release](https://github.com/SHMH-MCPs/forma-mcp-releases/releases/latest)
— run `Forma-MCP-Setup.exe` from it.
